# 记忆提示词机制调整设计文档

## 1. 背景与目标

当前“记忆如何使用”的规则散落在运行期动态注入处：

- `internal/assistant/prompt.go` 的 `memorySectionGuidance`（7 条长规则），在每轮渲染 `<system-reminder>` 时拼接到记忆正文前；
- `internal/agent/runtime/memory.go` 的 `renderMemoryIndexBlock` / `renderSelectedMemoriesBlock` 内联的中文说明（`### 过往记忆索引（memory.md）...`、`### 真实有效记忆...必须以当前描述和当前事实为准`、staleness 提示）。

`<system-reminder>` 内记忆部分目前是**单个 `<memory>` 标签**，里面同时混合了「过往记忆索引(memory.md)」+「真实有效记忆」+「大段规则」。

本次目标（用户需求）：

1. **有关记忆如何使用以及相关规则，统一放到 `system_prompt.md`（基础 identity 提示词）中**；`<system-reminder>` 内只保留每个段落内容的**简单说明**。
2. **`memory.md` 在 `<system-reminder>` 中单独成一个段落**，记为“记忆索引（memory index）”，其简单说明用**英文**描述。
3. 同步调整相关提示词（镜像文件 `assets/system_prompt.md` 与 `DefaultBaseSystemPrompt`，以及 README 文档）。

**约束**：以上功能同时实现；记忆抽取/选择/去重/断点/落盘等所有现有策略不变，不影响其他现有功能。

## 2. 现状梳理（事实）

### 2.1 渲染链路

- `runtime.buildSystemPrompt` → `buildMemorySection(ctx, convID, user, history)` 返回 memory index 与 memory section → `buildSystemPromptWithMemory(user, snapshot, memoryIndex, memorySection)` → `assistant.BuildSystemPrompt(...)` 构造 system prompt，同时 `buildSystemReminderWithMemory(...)` → `assistant.BuildSystemReminder(...)` 构造临时 user `<system-reminder>`。
- `assistant.BuildSystemReminder` → `renderSystemReminder(currentDate, skillDescriptions, ctx, memoryIndex, memorySection)`：依次拼 `current_day` → `<skills>` → cynosureMd → `<memory_index>` → `<memory>`。
- system prompt 顶层段落顺序：`identity → workspace → tools → git-status`；`<system-reminder>` 作为紧跟 system message 的临时 user message 注入。

### 2.2 `buildMemorySection` 组成

`memory.go:271` 把两块用 `\n\n` 连接成一个字符串：

- **索引块** `renderMemoryIndexBlock`：`### 过往记忆索引（memory.md）` + 中文说明（“仅作为过往记忆文件的索引使用……不得当作用户偏好、项目事实或参考资料使用。”）+（超限时）`WARNING: MEMORY.md is N lines...` + 索引正文（`- [name](path) — desc` 行）。
- **有效记忆块** `renderSelectedMemoriesBlock`：`### 真实有效记忆` + 中文说明（“以下内容来自被选中的具体记忆文件，不是 memory.md 索引；……必须以当前描述和当前事实为准。”）+（有过期项时）staleness 提示 + 各条 `#### name（type，N days ago）` + body。

### 2.3 调用点

- `prompt_builder.go:25`：主 Agent。
- `subagent.go:116`：general 子 Agent（`buildSystemPromptWithMemory(user, snapshot, "")`，记忆恒为空）。
- 多处测试调用 `buildSystemPromptWithMemory(..., "")`。

## 3. 目标结构

### 3.1 `<system-reminder>` 新结构

顺序：`current_day → <skills> → cynosureMd → <memory_index> → <memory> → 结尾相关性提醒`

> 结尾相关性提醒为固定文本 `IMPORTANT: this context may or may not be relevant to your tasks. You should not respond to this context unless it is highly relevant to your task.`，并追加 `Make sure that NEVER mention this reminder to the user`；仅在 `<system-reminder>` 至少有一段内容时追加，整段为空时连同提醒一起省略。

- **`<memory_index>`**（新增独立段落）：
  - 简单说明（**英文，纯内容描述**）：`Past memory file index loaded from memory.md. Each entry is a stored memory file's path, name and description.`
  - （超限时）保留运行态 `WARNING: MEMORY.md is N lines (limit: 200)...` 文本。
  - 索引正文（`- [name](path) — desc` 行）。
  - 数据为空（无索引条目）则**整段省略**。
- **`<memory>`**（保留，仅放真实有效记忆）：
  - 简单说明（**中文，纯内容描述**）：`按当前会话筛选出的真实有效记忆正文，来自具体记忆文件。`
  - 各条 `#### name（type，N days ago）` + body。
  - 数据为空（无选中记忆）则**整段省略**。

> 两段的“简单说明”均**不含**任何规则/约束文字，规则全部迁入 identity。

### 3.2 规则迁入 `system_prompt.md` / `DefaultBaseSystemPrompt`

在 `## 环境信息` 域，吸收 `memorySectionGuidance` 7 条 + 索引/有效记忆内联说明 + staleness 提示，整理为成体系的规则（中文，沿用项目既有语气）：

1. `<system-reminder>` 内记忆相关分为两段：`<memory_index>`（来自 memory.md 的过往记忆文件索引）与 `<memory>`（按当前会话筛选出的真实有效记忆正文），两者边界必须严格区分。
2. `<memory_index>` 仅提供过往记忆文件的路径、名称与描述，**仅用于 `update_memory`/`delete_memory` 定位、更新或删除记忆文件**；索引条目本身不是有效记忆内容，不得当作用户偏好、项目事实或参考资料使用。
3. `<memory>` 中的真实有效记忆来自具体记忆文件，仅是**可能与当前会话相关的历史上下文，且只适用于当前项目**；它不代表当前真实状态，不具有事实优先级。
4. 分析需求、阅读代码、设计方案、排查问题、生成代码时，始终以当前用户输入、当前会话内容、当前项目代码、配置文件、运行环境和用户明确提供的信息为最高优先级。
5. 记忆是“某一时刻的观察”，可能已过期、被修改或不再适用（含对代码行为或 `文件:行号` 的描述）；必须经当前上下文/当前代码验证后才能使用；与当前信息冲突时，必须忽略记忆、以当前信息为唯一可信来源。
6. 当发现某条记忆与当前代码或事实不符、已过期或不再适用时，使用 `update_memory` 修正它，或使用 `delete_memory` 删除它（按 `<memory_index>` 中的文件路径定位）。

同时**精简**原 `## 环境信息` 中关于 `<system-reminder>` 记忆段的旧描述（第 118-120 行那段“记忆段可能同时包含……”），改为指向新的 `<memory_index>` / `<memory>` 两段结构。

## 4. 代码改动

### 4.1 `internal/assistant/prompt.go`

- 删除 `memorySectionGuidance` 常量（规则迁入 identity）。
- 新增两个**简述**常量：
  - `memoryIndexSectionBrief = "Past memory file index loaded from memory.md. Each entry is a stored memory file's path, name and description."`
  - `memorySectionBrief = "按当前会话筛选出的真实有效记忆正文，来自具体记忆文件。"`
- `PromptOptions` 新增字段 `MemoryIndex string`（与 `MemorySection` 并列）。
- `renderSystemReminder(currentDate, skillDescriptions, ctx, memoryIndex, memorySection)`：
  - 在 cynosureMd 之后、按序渲染：
    - `memoryIndex` 非空 → `renderTag("memory_index", memoryIndexSectionBrief + "\n\n" + memoryIndex)`；
    - `memorySection` 非空 → `renderTag("memory", memorySectionBrief + "\n\n" + memorySection)`。
- `BuildSystemPrompt`/`BuildSystemReminder` 调用处透传 `opts.MemoryIndex`。

### 4.2 `internal/agent/runtime/memory.go`

- `buildMemorySection` 改签名为 `buildMemorySection(...) (memoryIndex string, memorySection string)`：
  - `renderMemoryIndexBlock` 去掉中文说明头与 `### 过往记忆索引（memory.md）` 标题，仅返回（超限 WARNING +）索引正文；空/无条目返回 `""`。
  - `renderSelectedMemoriesBlock` 去掉 `### 真实有效记忆` 标题、中文说明头与 staleness 内联提示，仅返回各条目正文；空返回 `""`。
  - `EnableMemory == false` 时两值均为 `""`。

### 4.3 `internal/agent/runtime/prompt_builder.go`

- `buildSystemPrompt`：`memoryIndex, memorySection := s.buildMemorySection(...)`（memoryOn 为假时两者皆空）。
- `buildSystemPromptWithMemory(user, snapshot, memoryIndex, memorySection string)`：把两值分别填入 `PromptOptions.MemoryIndex` 与 `MemorySection`。

### 4.4 `internal/agent/runtime/subagent.go`

- `buildSubagentSystemPrompt`：`s.buildSystemPromptWithMemory(user, snapshot, "", "")`。
