## [产出] go-agent 项目概况

助手向用户介绍了当前项目 go-agent 的完整概况，包括技术栈、目录结构、核心架构、内置工具和配置要点。

项目：go-agent，纯本地运行TUI通用智能体，用Go 1.26.1编写，使用Deepseek LLM，Bubble Tea TUI。目录结构包括main.go、internal/等。核心流程：用户输入→TUI→Runtime主循环→构建prompt→LLM调用→解析响应→工具执行或文本回复。内置工具：load_skill,bash,read_file等。关键特性：上下文压缩、项目级记忆、历史恢复、Skill系统、MCP集成、TUI快捷命令。配置：config.json和settings.json。
