## [产出] go-agent 项目详细总结

用户要求总结当前项目，助手提供了关于 go-agent 项目的完整概述，涵盖技术栈、项目结构、核心架构流程和关键特性。

项目定位：一个用 Go 编写的 TUI 通用智能体（general-purpose agent），运行在本地终端中，提供类助手对话式交互体验。

技术栈：Go 1.26 + Deepseek LLM（OpenAI 兼容 API）+ Bubble Tea + Lipgloss + Glamour + SQLite + JSON 配置 + MCP SDK。

项目结构：按 internal/{cli, tui, config, llm, agent, tools, local, sessions, logger, safety, idgen, assistant} 分层组织，外部有 skills/、workspace/、docs/、.link/memory/ 等目录。

核心架构流程：用户输入 → CLI 初始化 → TUI → Runtime 主循环（构建提示词 → 调用 LLM → 解析响应：工具调用时循环，纯文本回复返回用户）→ 会话持久化（SQLite）。

关键特性：工具系统（bash、文件操作、todo_write 等）、MCP 集成、技能系统（可加载本地技能文件）、上下文压缩（多种策略）、记忆系统（Markdown 文件跨会话）、子智能体、钩子系统、TUI Markdown 渲染、路径安全检查。
