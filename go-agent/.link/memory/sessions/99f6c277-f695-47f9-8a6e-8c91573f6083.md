## [产出] 项目阅读总结：go-agent 项目结构与关键特性

助手已完整阅读终端 TUI 通用智能体 go-agent 项目的全部代码，并输出详细总结，涵盖技术栈、项目结构、核心架构、关键特性等。

go-agent 是一个基于 Go 语言编写的终端 TUI 通用智能体，核心定位为本地运行的对话式通用型 agent。技术栈：Go + Deepseek LLM + Bubble Tea TUI + SQLite/内存存储 + MCP 集成。项目结构包括 main.go、internal/cli、internal/tui、internal/config、internal/llm、internal/agent（含 runtime、storage、compression、hooks）、internal/local、internal/mcp、internal/tools 等。核心流程：用户输入 → CLI 初始化 → TUI 启动 → Runtime 主循环（构建 prompt → 调用 LLM → 执行工具 → 循环至纯文本返回）。关键特性包括工具系统（bash、文件操作、子智能体等）、MCP 动态集成、技能系统、基于 Markdown 的记忆系统、上下文压缩系统（多种压缩策略）、钩子系统、TUI 界面（流式显示、工具可视化等）。数据模型涵盖 User、Conversation、Message、ToolCall、PersistedOutput、Memory 等。配置通过 JSON 文件，安全策略可配置。启动流程：解析 CLI 参数 → 加载配置 → 初始化 LLM → 初始化存储 → 加载 MCP、技能、记忆 → 启动 TUI。设计亮点包括无 SQLite 依赖（内存存储接口抽象）、持久化输出机制、多级上下文压缩、MCP 动态集成、会话恢复、安全边界。完整总结已在对话中给出。
