# 周报撰写最佳实践参考

## 一、周报的阅读对象

在撰写周报前，明确你的阅读对象：
- **直属上级**：关注工作结果、项目进度、风险问题
- **跨部门同事**：关注协作内容、依赖关系
- **高层领导**：关注战略对齐、核心指标、关键里程碑
- **自己**：周报也是个人复盘的工具

## 二、周报的黄金结构

### 金字塔原理
最重要的信息放在最前面，次要信息依次排列。

```
最上层：核心成果 / 关键数据（1-2句话）
  ↓
中层：重点工作详情（按重要性排序）
  ↓
下层：常规工作 / 细节补充
  ↓
底层：问题、计划、支持需求
```

## 三、常见问题与改进

### ❌ 常见问题
1. **流水账式**：简单罗列每日工作，缺乏重点
2. **过度谦虚**：弱化了自己的贡献和成果
3. **只有问题没有方案**：只抛出问题却没有解决思路
4. **缺乏数据支撑**：全是定性描述，没有定量证据
5. **和目标脱节**：工作内容与团队/公司目标没有关联

### ✅ 改进建议
1. **用成果说话**：每项工作都问自己"So What?"（所以呢？产生了什么价值？）
2. **主动对齐目标**：将工作与 OKR/KPI 关联
3. **问题配方案**：提出问题时，至少给出 1-2 个解决方案选项
4. **数据化表达**：能用数字的地方尽量用数字
5. **适当的可视化**：使用表格、进度条等让信息更直观

## 四、不同场景的周报侧重点

| 场景 | 侧重点 | 建议篇幅 |
|------|--------|---------|
| 项目冲刺期 | 进度、完成度、风险 | 详细 |
| 平稳运维期 | 稳定性、优化、常规工作 | 中等 |
| 项目启动期 | 调研、方案、计划 | 中等 |
| 个人成长期 | 学习、尝试、复盘 | 简洁 |
| 团队管理期 | 团队状态、人员、协调 | 详细 |

## 五、周报的语气把控

- **专业但不生硬**：用行业术语展现专业性，但不要堆砌术语
- **客观但不冷漠**：用事实说话，但体现对工作的热情
- **自信但不自满**：充分展示成果，但保持谦虚学习的态度
- **直面问题但不消极**：坦诚面对问题，同时传递积极解决问题的信号

## 六、实用的周报技巧

1. **提前积累**：每天花 5 分钟记录当天的关键工作，周末汇总就轻松了
2. **对标检查**：写完周报后检查：核心数据是否清晰？成果是否突出？问题是否闭环？
3. **格式统一**：保持每周的格式一致，方便领导和自己做纵向对比
4. **适度留白**：不要写得太满，留出领导批注的空间
5. **回顾上周计划**：检查上周承诺的事项是否完成，形成闭环
