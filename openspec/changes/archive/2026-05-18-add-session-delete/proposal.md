## Why

当前 go-agent Web 端已经支持创建、查看和继续对话，但用户一旦创建了无效、测试性或不再需要的会话，就只能一直保留在列表里，前端也没有对应清理入口。随着会话数量增加，用户会更难管理聊天历史，因此需要补齐会话删除能力，并让前后端一起支持安全删除当前用户自己的聊天会话。

## What Changes

- 为 Web 聊天会话新增删除能力，允许已认证用户删除自己名下的 conversation
- 在后端新增会话删除接口，并校验只能删除当前用户拥有的会话
- 删除会话时同时清理该会话关联的消息记录、工具调用记录以及缓存中的活跃会话上下文
- 在前端会话列表中增加删除入口，并在删除当前激活会话后自动切换到剩余会话或空状态
- 为前后端补充删除成功、无权限访问和删除后界面刷新等关键场景验证

## Capabilities

### New Capabilities
- 无

### Modified Capabilities
- `web-chat`: 扩展网页聊天能力，使用户可以在会话列表中删除自己的聊天会话并获得正确的界面反馈
- `conversation-storage`: 扩展会话持久化能力，使删除会话时能一并移除关联持久化数据与缓存状态

## Impact

- 影响后端会话 API 与鉴权校验逻辑，包括 `go-agent/internal/web/app/server.go`
- 影响会话存储层删除逻辑与缓存清理，包括 `go-agent/internal/web/storage/store.go`
- 影响前端 API 封装与聊天列表交互，包括 `web/src/api.ts` 和 `web/src/App.tsx`
- 影响相关前后端测试，覆盖删除后列表刷新、当前会话切换和跨用户删除限制
